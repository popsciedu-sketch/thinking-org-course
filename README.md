# 思考的整理學 · 互動教學（繁中消化版）

原著：外山滋比古《思考の整理学》／譯本參考：韋杰岱等繁中譯本。  
本站內容為**概念消化與練習材料**，非原文照搬。

## 怎麼開啟

直接用瀏覽器開啟 `index.html`，或把整個資料夾部署到任意靜態網站託管。

```bash
cd thinking-org-course
python3 -m http.server 8080
# 瀏覽 http://localhost:8080
```

## 結構

| 路徑 | 說明 |
|---|---|
| `index.html` | 總覽與六部地圖 |
| `parts/p1.html`–`p6.html` | 六部理論：概念、SVG 圖、互動問答（每部≥3）、總結、進度勾選 |
| `parts/practice.html` | 紙筆練習導覽（無電腦軟體實操） |
| `assets/worksheets/` | 可下載工作表 |
| `css/style.css` / `js/app.js` | 樣式與進度／測驗邏輯（localStorage） |
| `DRIVE_UPLOAD_MANIFEST.md` | Google Drive 上傳清單與連結 |

## 學習建議

1. 依Ⅰ→Ⅵ閱讀；每部做完測驗並勾「已讀完」。
2. 到紙筆練習頁下載工作表，實際寫一週。
3. 重點是轉成自己的做法，不是背書中句子。
